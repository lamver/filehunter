FileHunter beta


      
Files from all your drives, cloud storage and computers in one window. Drives are scanned once; after that the catalog updates itself from system signals: files created, changed or deleted, drives connected or disconnected.

Share this computer with another

          
Check what the other computer will see, create a code and enter it there. That computer gets access to what you checked here but shares nothing of its own. The code works once and is valid for 10 minutes.

          

          

          
        

        

          
Connect with a code

          
Paste the code created on the other computer. You will see what was shared there; this computer shares nothing with it — you can do that later (right-click the device → “Access to this computer…”).
